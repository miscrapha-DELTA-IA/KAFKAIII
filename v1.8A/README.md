# KAFKA III v1.8A — static gain–loss map

Original package: [PACOTE_KAFKA_III_V1_8A_MAPA_GANHOS_PERDAS_CINZENTO.zip](PACOTE_KAFKA_III_V1_8A_MAPA_GANHOS_PERDAS_CINZENTO.zip).

The archive contains the static map implementation, pre-simulation protocol, defensible-thesis plan, reproduction instructions, tests, stdout logs, paired contrasts, summary tables, post-hoc zones, and the original SHA-256 manifest.

The two large `replicacoes.csv` files are present as extracted, Git-tracked CSVs under `source/outputs/` and `source/outputs_replication/`. The original ZIP is also retained unchanged. The archive passed ZIP integrity testing and its internal SHA-256 manifest was retained. The package documents exploratory synthetic scenarios; its results must not be interpreted as clinical validation or as a general superiority result.
