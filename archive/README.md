# Archive and provenance

This directory preserves source bundles and recovery material that should not be mistaken for separate methodological stages.

- [source_archives](source_archives/) contains early reproducibility packages that do not map cleanly to a current version directory.
- [recovery](recovery/) retains a historical recovery bundle under its original filename. It is archival context, not part of the scientific method, not a version label, and not a component of the KAFKA III architecture.

Version-specific source archives are kept beside their corresponding version folder. The supplied archive bytes are preserved unchanged; only their repository filenames are normalized to English kebab-case. The original supplied filenames and SHA-256 values are recorded in [the package-name provenance map](../provenance/package-name-map.md). ZIP members and package-level checksum manifests are not modified.
